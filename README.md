# TaskFlow FAQ & Documentation Support Chatbot

An intelligent, grounded question-answering assistant built with **Python**, **Groq AI (LLaMA 3.3)**, **ChromaDB**, and **Streamlit**.

The chatbot answers questions **only** from your uploaded PDF documentation (located in `docs/`), provides accurate citations with exact source documents and page numbers, and handles service hiccups gracefully.

---

## 🚀 Quick Start Guide

### 1. Get a Free Groq API Key
1. Go to [console.groq.com/keys](https://console.groq.com/keys) (100% free, no credit card required).
2. Create an API key and copy it.
3. Open the `.env` file in the project folder and paste your key:
   ```env
   GROQ_API_KEY=gsk_your_actual_key_here
   ```
   *(Alternatively, you can paste the key directly into the sidebar text box in the web interface!)*

### 2. (Optional) Re-Index Documents
All 5 sample PDFs in `docs/taskflow/` are already indexed into ChromaDB.
If you add new PDFs or modify existing ones, re-index at any time:
```bash
python ingest.py
```
*(Or click the **🔄 Re-index All PDFs** button in the Streamlit sidebar!)*

### 3. Verify Vector Search in Terminal
Test semantic search directly from your command line:
```bash
python test_search.py "What is the refund policy?"
```

### 4. Launch the Streamlit Web Chat Interface
Run the Streamlit application:
```bash
streamlit run app.py
```
Your browser will open to `http://localhost:8501`.

## 💡 How to Customize for a New Client

This project is built from the ground up for reusability:

1. **Swap the Documents**:
   - Delete the files in `docs/` and drop your new client's PDF files into `docs/`.
2. **Update `config.py`**:
   - Change `APP_TITLE` and `APP_SUBTITLE` to your client's name.
   - Adjust `WELCOME_MESSAGE` and sample questions.
   - Customize `SYSTEM_PROMPT` if you need special tone instructions.
3. **Re-Index**:
   - Run `python ingest.py` (or click **Re-index** in the UI).
4. **Done!** You now have a custom chatbot for a completely different company or product in under 5 minutes.

## 🛡️ Key Design & Safety Features

- **Strict Grounding**: The AI is instructed via prompt engineering to answer strictly from the retrieved document excerpts and never guess or hallucinate.
- **Source Transparency**: Every response provides pill badges indicating the exact document and page number, plus an expandable viewer to inspect the raw excerpts.
- **Local & Free Embeddings**: Vector embeddings use ChromaDB's local ONNX model (`all-MiniLM-L6-v2`) which runs 100% on your machine without external API costs or limits.
- **Graceful Error Handling**: If Groq's API is unreachable, encounters a rate limit, or the API key is missing/invalid, friendly alerts guide the user instead of crashing the interface.
- **Clear Chat**: A dedicated button in the sidebar resets the conversation at any time.
